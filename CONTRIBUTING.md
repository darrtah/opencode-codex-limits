# Участие в разработке

Спасибо за помощь! Перед изменением поведения создайте issue с описанием задачи. Для сообщений об уязвимостях используйте [SECURITY.md](SECURITY.md), а не публичный issue с секретными данными.

## Локальная проверка

Требуется Node.js 24+ и npm:

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run check
npm run scan
```

GUI собирается из исходников. Включайте в PR соответствующий обновлённый `gui-experimental.cjs`; не редактируйте bundle вручную. Зафиксированные зависимости описаны в `package-lock.json`; исторический `bun.lock` не используется текущим процессом сборки.

Тесты используют синтетические данные и не требуют авторизации. Новые сценарии должны включать проверки отсутствующих/неверных полей, смены аккаунта, ошибки обновления и восстановления. Не используйте реальные токены или идентификаторы аккаунтов в fixtures.

При отчёте о проблеме укажите версию OpenCode, ОС, способ входа (без кодов и токенов), название тарифа и шаги воспроизведения. Скриншоты очищайте от личных данных.

Первая версия поддерживает только Codex. Go/Claude можно обсуждать отдельно, но без тестов реального подключения нельзя заявлять поддержку этих подписок.
